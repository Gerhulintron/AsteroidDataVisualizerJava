Asteroid Data Visualizer

Explore NASA NeoWs data for reported close approaches to Earth on your selected date. Each circle represents an asteroid; its size reflects the midpoint of NASA’s estimated diameter range.

In Layered view, the largest circles sit behind the smallest, and the gap from each circle’s bottom edge to the blue horizon represents miss distance. Linear view spreads circles horizontally by identity, using the same bottom-to-horizon distance encoding with its own scale—not actual sky positions.

Colours are artistic choices, not hazard ratings. Sizes and distances are scaled independently within each date: this is an illustrative comparison, not true scale, an orbit simulation or a prediction of impact. Demo mode uses synthetic examples.
